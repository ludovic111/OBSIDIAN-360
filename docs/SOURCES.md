# Sources techniques

Les relevés locaux sont prioritaires pour l’état de cet exemplaire. Les pages historiques peuvent décrire un support ancien ; ne pas les traiter comme une garantie de compatibilité actuelle.

- [Free60 : patches du noyau](https://github.com/Free60Project/linux-kernel-xbox360) — patch `6.18-xenon0.30` examiné ; inventaire et hash dans `research/metadata/`.
- [LibXenon : modes vidéo](https://github.com/Free60Project/libxenon/blob/master/libxenon/drivers/xenos/xenos_videomodes.h).
- [Free60 : programmation vidéo](https://free60.org/Modesetting/).
- [Free60 : SMC](https://free60.org/Hardware/Console/SMC/).
- [Free60 : carte mémoire](https://free60.org/System-Software/Memory_Map/) — description historique de la fenêtre NAND ; notre tentative a gelé la console.
- [Free60 : démarrage](https://free60.org/System-Software/Boot_Process/).
- [Free60 : CPU](https://free60.org/Hardware/Console/Xenon_(CPU)/), [GPU](https://free60.org/Hardware/Console/Xenos_(GPU)/).
- [BadUpdate](https://github.com/grimdoomer/Xbox360BadUpdate), [FreeMyXe](https://github.com/FreeMyXe/FreeMyXe), [XeLL](https://github.com/Free60Project/xell-reloaded).
- [ABadAvatar](https://github.com/shutterbug2000/ABadAvatar).
- [RGH](https://free60.org/Hacks/Reset_Glitch_Hack/), [code RGH3](https://github.com/15432/RGH3).
- [ArchPOWER](https://repo.archlinuxpower.org/).

Aucun code tiers n’est présenté comme une découverte originale. Les binaires volumineux, clés et dumps firmware ne sont pas versionnés.
